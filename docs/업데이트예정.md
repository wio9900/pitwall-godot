## 📝 코드초안(`코드초안_C_F_E_32.md`) 적용 시 주의 — C·F·E 는 설계 참고용, 그대로 넣지 말 것
- C-4 AI 이적: F1 시장 드라이버엔 `tyreMgmt`·`wet`·`aggr`·`def` 없음 → 로스터에 넣으면 주말 화면 멈춤. 키 변환 필요
- C-2 스폰서: 오퍼에 `sector` 키 없음 → 하나 계약하면 나머지 오퍼 전부 사라짐
- C-1 오너: 목표 미달 뉴스에 "60%%" 로 % 두 번 찍힘
- C-3 스카우트: AI 엔지니어 데려가기(`rival`)는 이미 있음 — 중복이고 AI 팀 성능 효과 없음
- F 차종: AI 팀 차종 미지정 → 내 차만 보정·BoP 받음(이길수록 나만 느려짐). 차이 ±1% 는 과함(절반 정도). 저장엔 차종 id 만
- E 피트레인: 서킷별 피트레인 좌표 데이터가 빠져 있음(본체 작업). `_stall_u` 는 `pit_idx` 기준이라 촘촘한 `pit_pts` 와 단위 안 맞음 → 박스 입구 쪽 몰림. 피트 시설은 매 프레임 말고 한 번 그려 재사용
