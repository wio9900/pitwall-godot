## 다음 — 묶음별 (순서: A → B → C → D → E → F)
### 묶음 A · 레이스 규정 — 시작은 시간제+급유부터 (다른 항목 측정이 시간제 기준)
- WEC: 르망 LMP2·LMGT3 브론즈·실버 각각 최소 25% / 일반 레이스 최소 주행 방식 검토 / LMGT3 골드·플래티넘 1명 제한
- F3 스프린트 레이스 (예선 상위 12명 역순)
- WEC 시간제 레이스 + 급유 개편 (같이 작업 — "완주까지" 계산이 시간 기준이어야 함)
  - 시간제: 랩 수 대신 압축된 레이스 시간, 시간 종료 후 선두 통과 시 체커. 화면에 "남은 시간" 시계 (게임 시계 기준 → 배속과 무관하게 정확)
  - 압축 비율을 레이스별로: 일반(6·8·10시간) 피트 4~6회, 르망 10~12회 수준
  - "총 랩 수" 기준 계산 → "예상 총 랩(남은 시간 ÷ 평균 랩)"으로 교체: 최소 주행, 등급 의무, 세트 수, AI 전략, 남은 랩 표시, 기록실·결과
  - SC·FCY 중 랩이 줄어드는 효과 → 연료 한 번 덜 넣기 같은 판단 가능
  - 피곤함 방지: 스틴트 계획표(일반 정차는 자동, 중요한 정차만 직접), 선택형 배속 자동 조절
    - 자동 조절은 내가 정한 배속보다 느리게만 (피트 창·SC 때), 상황 끝나면 내 배속으로 복귀
    - 자동으로 느려진 중 내가 배속 바꾸면 내 선택 우선, 그 상황 끝날 때까지 자동 개입 안 함
    - 설정에서 끄기 가능 (기본값은 작업 때 결정), 무전 선택지 창은 지금처럼 일시정지
  - [안전] race_sim advance()의 한 프레임 처리 상한(2000건) 걸리면 남은 일 건너뛰고 시계만 넘어감 → 상한 걸리면 시계를 마지막 처리 시점에 두고 다음 프레임에 이어서 처리
  - 급유 시간 = 기본 3초 + 넣는 양 비례 (지금은 양과 무관하게 고정)
  - 피트 탭 급유량 슬라이더 (단위: 표준 모드 기준 랩), 0.5랩 단위 + −/+ 버튼, 빠른 선택(가득 / 완주까지 / 안 함)
  - 슬라이더에 "완주 필요량" 표시선, 최소 = 현재 연료, 최대 = 탱크(스틴트 에너지 상한)
  - 표시: 표준 N랩 · 세이브 N랩 · 리치 N랩 / 급유 시간 약 N초 / 연료 무게 랩당 +N초 / 다음 계획 정차·완주에 모자라면 경고
  - AI: 마지막 정차는 완주분만(스플래시), SC·FCY 이른 정차는 필요한 만큼
  - 밸런스: WEC 여러 판 돌려 평균 피트 손실·순위 변동 비교, 풀 급유 시간 재조정
- WEC 클래스별 타이어 규정 (2026 기준)
  - LMGT3: 드라이 = Goodyear 미디엄 1종 (게임 이미 일치), 일반 레이스는 할당이 늘어 매 정차 새 세트 가능 (6시간 24본=6세트, 8시간 32본, 10시간 40본, 연습 16본) → 지금 세트 비율 0.75 → 정차마다 교체 가능하게, AI도 일반 레이스는 매번 교체 위주
  - LMGT3 르망: 별도(적은) 할당, 한 세트로 3~4스틴트 → 르망만 세트 제한 유지·AI 다중 스틴트
  - 하이퍼카(Michelin)·LMP2·LMP3 할당·컴파운드도 같은 방식으로 재확인
  - 연도별 규정은 데이터 파일로 (2027 Goodyear 신규 레인지 예정)
- 기계 고장 확률 재조정
  - 측정(80판): 고장 리타이어 한 대당 F1 0.5% · WEC 0.2% — 레이스 압축(15~30랩)에 랩당 확률을 그대로 둬서 현실보다 크게 낮음
  - 압축률만큼 보정해 평균 신뢰성 팀 한 대당 3~5% (상한 5% 권장)
  - "반쯤 고장" 추가: 출력 저하·기어 고착 등 달리면서 버티는 문제 → 피트 수리 vs 버티기 판단
  - WEC: 개러지 수리 비율·시간을 클래스·고장 종류별로
  - 보정 후 calib 재측정 (봇 vs AI 차이)
- 주행 지시·페이스 장단점 명확화 + 선택 시 표시
  - 원칙: 모든 모드에 확실한 장점 1~2개 + 확실한 대가 1~2개, 공짜 모드 없음
  - 추월(앞차 1.5초 안에서만 작동): 추월 확률↑·푸시로 랩타임 약간↓ / 마모↑·실수↑·접촉↑
  - 방어(뒤차 1초 안에서만 작동): 상대 추월 확률↓ / 랩타임↑·마모↑·접촉 위험
  - 유지: 마모↓·실수↓ / 랩타임 약간↑·뒤차 추월 쉬워짐
  - 연비: 연료↓·마모↓·과열 해제 / 랩타임↑·뒤차 추월 쉬워짐
  - 페이스(공격·표준·세이브)도 같은 형식으로 표시
  - 조건이 안 맞으면(앞·뒤차 멀리) 버튼에 "대기 중" 표시
  - 선택 시 버튼 아래 한 줄: 장점(초록) · 단점(빨강), 숫자 포함 (예: "랩당 +0.35초 · 연료 −14%")
  - AI도 같은 효과, calib 재측정

### 묶음 C · 커리어 경영 (서로 얽힘, 이 순서로)
1. 경제 밸런스 점검 (리그 계수 더 가파르게 등, 몇 시즌 시뮬로 자금 곡선 비교)
   - 초기 예산 축소 (지금 너무 많음)
     - 현재 신규 F3 팀: 시작 자금 5.2M + 오너 1년차 5.0M = 약 10.2M, F3 시즌 고정 지출(운영비+고정비 0.3M × 17경기) 약 5.1M → 첫날부터 약 5M 여유 → 설비 Lv 약 1M씩이라 개막 전에 5단계쯤 바로 올릴 수 있음
     - 목표: 첫 시즌은 "설비 하나 or A급 엔지니어 하나" 수준의 선택만 가능, 나머지는 성적·스폰서로 벌어야 함
     - 오너 투자: 매 시즌 자동 지급 → 일부는 조건부(포인트 획득·목표 순위 달성 시 분할 지급)
     - 기존 팀 시작 예산(페라리 13.5M 등)도 코스트캡·수입 흐름 기준으로 재조정
     - 연구 철학 변경 비용(지금 0.4M×리그 계수)도 같이 재조정
     - 검증: 봇으로 첫 2~3시즌 돌려 자금 곡선, 첫 시즌 업그레이드 개수, 파산 위험 비교
2. 스폰서 개편 (자리별 등급 탭 대형·중형·소형·지역, 업종 독점, 조건·보너스 다양화, 협상, 리그 연동, AI 경쟁, 가상 브랜드)
3. 인력·스카우트 개편 (등급 탭 S~D, 성향·나이·성장·계약·장단점 특성, 스카우트 인력)
   - 팀 궁합 (성능 보너스가 아니라 효율·비용에 연결 — 보너스 중첩·정답 조합 방지)
     - 본부 지역 ↔ 엔지니어 출신: 같은 지역은 계약금 싸고 후보 많음, 먼 지역은 이주비
     - 연구 철학 ↔ 엔지니어 성향: 맞으면 그 분야 개발 속도 +5% 안팎 (즉시 성능 아님)
     - 안 맞아도 페널티 없음 (보너스만 없음)
     - 지역·철학·엔지니어 보너스 합계 상한 (예: 한 분야 최대 +2%)
     - 철학 변경 시 궁합 깨질 수 있음 → 변경 판단에 무게
     - AI 팀도 자기 본부·철학에 맞는 엔지니어 우선 영입 (시장 경쟁)
     - 검증: 같은 조건 커리어 "궁합 맞춤 / 무시" 몇 시즌 비교, 차이 0.5계단 이내 목표
   - 인물: 엔지니어·스태프 전원 가상 인물 → 이름 생성기(data/names.json, career gen_person) 재사용
     - 국적 = 출신 지역 (names.json region_nat 매핑 있음) → 본부 지역 궁합에 연결
     - 후보 수 확대: 파트당 20명 이상 (등급 탭 S~D, 탭당 4~6명), 시즌마다 갱신 + 시즌 중 소수 추가(방출·은퇴 복귀)
