# Pit Wall (Godot)

F1·WEC 피트월 전략 시뮬레이션. 원래 단일 HTML로 만들던 게임을 Godot 4.7로 옮기는 중이에요.

## 실행하는 법

1. **Godot 4.7** 실행 → 프로젝트 매니저에서 **Import(가져오기)** → 이 폴더의 `project.godot` 선택 → **Import & Edit**
   - 처음 한 번만 하면 되고, 다음부터는 목록에서 더블클릭하면 열려요.
2. 에디터 오른쪽 위 **▶ (F5)** 를 누르면 게임이 실행돼요.
3. 업데이트를 받을 때는 GitHub Desktop에서 **Fetch origin → Pull origin** 을 누른 뒤 Godot에서 다시 ▶.

## 에러가 났을 때

Godot 에디터 아래쪽 **디버거(Debugger)** 또는 **출력(Output)** 탭의 빨간 글씨를 캡처해서 Claude에게 보내주세요.

## 폴더 구조

```
data/              팀·드라이버·엔진·서킷 데이터 (JSON) — 숫자 조정은 여기서
scripts/sim/       레이스 시뮬레이션 (규칙·물리·AI) — 화면과 무관
scripts/data/      데이터 로더
scripts/ui/        화면 (메뉴·HUD·레이스 뷰)
scenes/main.tscn   시작 씬
tests/             헤드리스 테스트
```

```
godot --headless --path . --script res://tests/sim_smoke.gd
```
